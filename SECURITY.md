# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub Issue for security vulnerabilities.

Instead, use GitHub's private vulnerability reporting: go to the [Security tab](https://github.com/fikua/fikua-starflux/security) and click **"Report a vulnerability"**. This opens a private advisory visible only to you and the maintainers, so the issue can be discussed and fixed before it's disclosed publicly.

Include, if possible:

- A description of the vulnerability and its potential impact
- Steps to reproduce it
- The affected version(s)

## Supported Versions

Starflux is in early development (no stable release yet). Security fixes are only provided for the latest release.

## Scope

This project processes FITS image files and, when packaged as a downloadable binary, is installed and run locally on the user's machine. Reports about malformed-FITS-file handling (parsing crashes, memory issues) are in scope and welcome.
